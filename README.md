# Clinical Antibiotic Encyclopedia 2026

تطبيق Android سريري يعمل بالكامل دون إنترنت، محوّل من موسوعة المضادات الحيوية التي أُعدّت لمراجعة البورد والعمل في الأجنحة وICU/NICU.

## المحتوى الحالي

- 108 بطاقات دوائية منظّمة.
- جرعات البالغين لكل بطاقة.
- تعديل الكلى وHD/CRRT/RRT كما ورد في المصادر.
- اعتبارات الكبد عندما يذكرها المصدر صراحة.
- الطيف والاستعمالات السريرية وPK/PD والإعطاء والسمية والمراقبة.
- 1,715 سجلًا قابلًا للبحث من 381 صفحة مصدر غير مكررة.
- بحث حسب الدواء، البكتيريا، موقع العدوى، الانتشار النسيجي، الزرع وAST/MIC.
- وضع Ward Quick Guide، حفظ العناصر، وواجهة عربية/إنجليزية قابلة للتبديل مع حفظ اختيار اللغة تلقائيًا.

## التنظيم السريري في الإصدار 1.2

- 9 عائلات دوائية رئيسية و29 مجموعة فرعية تغطي 108/108 بطاقة دوائية بلا تكرار.
- 9 عائلات جرثومية مرتبة حسب البنية والنمط السريري، مع خريطة طيف مرتبطة بالمصدر.
- قسم مستقل للاهوائيات يوضح الجراثيم، أماكن الاشتباه، خيارات التغطية والفجوات المهمة.
- 78 متلازمة عدوى ضمن 11 جهازًا؛ كل بطاقة تفصل الممرضات والعلاج التجريبي والعامل الذي يغيّر القرار.
- 10 مواقع توزيع نسيجي مع خلاصة الاستعمال/التجنب ومصفوفة اختراق مرتبة بدل الصفوف المتداخلة.
- بقيت السجلات الأصلية والبحث الشامل متاحين، لكنهما لم يعودا الواجهة الأساسية للتصفح.

## سلامة البيانات

يُولّد المحتوى بواسطة `tools/build_content.py`، ثم يُفحص بواسطة `tools/validate_content.py` ويُحزم كـ`encyclopedia.json.gz`. يضيف `tools/build_taxonomy.py` فهرسًا سريريًا حتميًا فوق البيانات الموجودة دون إعادة استخراجها. يحتوي التطبيق على SHA-256 ثابت لكل من قاعدة المحتوى والفهرس، ويرفض فتح أي نسخة ناقصة أو متغيرة.

الملف الجامع `Complete_Antibiotic_Master_Reference_2026.pdf` لم يُفهرس مرة ثانية لأن مجلداته الثلاثة موجودة بنسخها المستقلة؛ وبذلك لا تظهر النتائج مكررة.

## البناء

يتطلب Java 17 وAndroid SDK 36. يمكن بناء نسخة Debug بالأمر:

```bash
gradle --no-daemon :app:assembleDebug
```

هذا مرجع تعليمي. يجب التحقق من نشرة المنتج الحالية، antibiogram المحلي، AST/MIC، وظائف الأعضاء، الحمل، الحساسية، وطريقة RRT قبل وصف العلاج.
